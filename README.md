# Hi, I'm José Pablo 👋

Robotics & Digital Systems Engineer based in Monterrey, Mexico. I work where software meets hardware: computer vision, ROS2, industrial automation, and IoT in real factories.

- 🏭 **Now:** Field Service Engineer at [eMoldino](https://www.emoldino.com). I install and support wireless IoT mold-monitoring sensors for manufacturing clients
- ⚙️ **Before:** Control Engineer at Avant Assembly Systems. Commissioned automotive assembly lines with Allen-Bradley and Siemens PLCs and Keyence vision systems
- 🤖 **Research:** Intern at Chalmers University of Technology (Gothenburg). Ran ROS2, YOLOv5, and GPT-3.5 on a PAL Robotics TIAGo robot
- 🎓 B.Sc. Robotics & Digital Systems Engineering, Tecnológico de Monterrey (2025)

## Featured projects

| Project | What it does | Stack |
|---|---|---|
| [Puzzlebot](https://github.com/jpcedanos/puzzlebot) | Autonomous mobile robot that detects traffic lights and objects and adjusts its speed | ROS2, YOLO, Python |
| [Visuocontrol of a quasi-static robot](https://github.com/jpcedanos/Visuocontrol-of-a-quasi-static-robot) | One hand on a webcam drives a simulated 4-DOF arm with a gripper: pinch to pick up a Rubik's cube, with gravity and a timed task mode | MediaPipe, OpenCV, Python, Processing |

| [John Deere Smart Car](https://github.com/jpcedanos/JohnDeere_SmartCar) | Camera-guided car that follows a path autonomously, built with John Deere | STM32H745, RTOS, C |
